## ❓ Common Questions

**Q: Do I need a database?**
A: No! All data is static and stored in JSON/TOML/YAML files.

**Q: Can I add dynamic features later?**
A: Yes! The Axum backend can be extended for dynamic features.

**Q: How do I deploy this?**
A: See [DEPLOYMENT.md](./DEPLOYMENT.md) - 7 options available.

**Q: Is this production-ready?**
A: Yes! Clean code, error handling, caching, compression included.

**Q: Can I modify the styling?**
A: Yes! Edit `frontend/dist/style.css` to match your brand.

**Q: Where do I add my content?**
A: Update files in the `data/` folder (JSON, TOML, YAML).

## 🔥 Pro Tips

1. **Hot Reload**: Install `cargo-watch` for auto-rebuild on changes
2. **Logging**: Use `RUST_LOG=debug cargo run` for detailed logs
3. **Testing**: Run `cargo test` after making changes
4. **Performance**: Build with `cargo build --release` for production
5. **Data**: Add more files to `data/` folders to extend functionality
